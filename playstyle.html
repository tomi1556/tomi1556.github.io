だれと、遊ぶ？

遊び方に合わせて、最初にやることを5つにまとめました。

みんなで遊ぶ。

人の灯路につなぐほど楽になる世界です。話しかけなくても、だれかの灯路のそばに置けば、もういっしょに遊んでいます。

  1. 最初の広場のまわりで始める

    広場のまわりは、灯喰いに狙われません。

  2. だれかの灯路の16ブロック以内に置く

    灯路はだれの灯籠とでもつながり、5基で「二ノ灯」、15基で「三ノ灯」に上がります。

  3. 灯標で行き来する

    二ノ灯より上なら、名前のついた灯籠へ3秒で移動できます。

  4. 土曜21時の夜祭に出る

    何もしなければ参加です。ゲームは毎週かわります。

  5. 友達を呼ぶ

    招待1人で「白銀」、3人で「藤」、5人で「曙」の色がもらえます。

/tomoshibi list
行ける灯標
/tomoshibi go 名前
灯標へ移動
/yomatsuri
次の夜祭
/tomoshibi invite
招待コード

人の建物には手を出さないでください。灯籠は守られていますが、建物は守られていません。

身内で遊ぶ。

友達や家族と、ひとつの拠点を育てる遊び方です。Java版と統合版がまざっていても、同じ世界に入れます。

  1. 全員が同じアドレスで入る

    tomoshibara.life。統合版はポートを 5156 に。

  2. 呼んだ人の招待コードを入れる

    入ってから7日以内に /tomoshibi code コード。

  3. おたがいを「仲間」にする

    /tomoshibi trust 名前。仲間は、あなたの灯籠に名前をつけたり、取り除いたりできます。

  4. 拠点をひとつの灯路網にする

    16ブロック以内に置けばつながります。みんなで置けば、すぐ二ノ灯です。

  5. 集合場所の灯標をつくる

    /tomoshibi name 集合 で名前をつければ、全員 /tomoshibi go 集合 で集まれます。

/tomoshibi trust 名前
仲間にする・外す
/tomoshibi name 名前
灯標にする
/tomoshibi home
帰る場所へ
/tomoshibi color 色
灯りの色

「仲間」は灯籠を取り除ける権利です。本当に信頼できる人だけにしてください。ほかの人とつなげたくなければ、人の灯路から16ブロック以上離れて建てます。

ひとりで遊ぶ。

ひとりでも、最後まで遊べます。小さな拠点は守られていて、技と図鑑と証は自分のペースで埋められます。

  1. 最初の24時間で拠点をつくる

    来てから24時間は、まわりに灯喰いが来ません。

  2. 小さな拠点は狙われない

    灯籠が3基より少ない灯路網と、地下や高い塔の灯籠は狙われません。

  3. 自分の灯籠を5基つなぐ

    ひとりでも二ノ灯になり、灯標どうしを行き来できます。

  4. 灯技を育てる

    /waza。遊んだ道の Lv が上がり、毎日3つの「今日の務め」もあります。

  5. 図鑑と証を埋める

    灯魚は106種、灯の証は263個あります。

/waza
灯技
/waza fish
灯魚図鑑
/akashi
灯の証
/yomatsuri out
夜祭を見送る

迷ったら画面の下を見てください。灯りの外では、いちばん近い灯りの方角が出ます。
