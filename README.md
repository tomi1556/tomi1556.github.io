# 灯原（ともしばら）公式サイト

ビルド不要の静的サイトです。このフォルダの中身をそのまま置けば公開できます。

## ページ

| ファイル | 内容 |
|---|---|
| `index.html` | トップ（アドレス、三つの特徴、体験、予告編、次の夜祭、シーズン1） |
| `start.html` | はじめる（機種別の入り方、最初の夜、コマンド、よくある質問） |
| `guide.html` | 遊び方（灯籠と灯路、長い夜、灯喰い、加護と欠片、灯標・色・招待） |
| `events.html` | 夜祭（始まり方、4つのゲーム、ごほうび、シーズンの予定） |
| `rules.html` | きまり（禁止事項、守られていること、対応の流れ、連絡先、保護者の方へ） |
| `404.html` | ページが見つからないとき |

## GitHub Pages で tomoshibara.life に公開する

1. GitHub に新しいリポジトリを作り、このフォルダの中身をすべてアップロードする（`CNAME` も含める）
2. リポジトリの Settings → Pages で、Branch を `main`、フォルダを `/ (root)` にして保存する
3. ドメインの管理画面で、DNS を次のように設定する
   - `A` レコード：`185.199.108.153` `185.199.109.153` `185.199.110.153` `185.199.111.153`
   - `www` の `CNAME` レコード：`<ユーザー名>.github.io`
4. Settings → Pages の Custom domain に `tomoshibara.life` と出ていることを確かめ、Enforce HTTPS に印をつける

マインクラフトのサーバー本体は別の機械で動くので、ゲーム用には `play.tomoshibara.life` などの別名を用意するか、
サイトとサーバーを同じアドレスにする場合は SRV レコード（`_minecraft._tcp`）でサーバーの場所を指定してください。

## 内容を変えるとき

- 文章は `build.py` の中にあります。書き換えたら `python3 build.py` で全ページを作り直します（Python 3.12 以降）
- できあがった `.html` を直接書き換えてもかまいません
- アドレス、Discord の招待リンクは `build.py` の先頭と、`assets/site.js` の先頭にあります
- シーズンの開幕日時は `assets/site.js` の `SEASON_START` です
- 数値（敵の強さ、欠片の確率など）は、プラグインの設定を変えたら `guide.html` の表も合わせて直してください

## 公開前に確かめること

- 対応バージョン（`start.html`：Java版 26.2）と、統合版のポート（19132）が実際の設定と合っているか
- Discord に「はじめての方」の案内（ゲーム機からの入り方）を用意したか
- 「きまり」に書いた、建物をこわされたときの復元（記録を残すプラグインが必要です）
- 大夜祭の日付（`events.html`：12月12日の予定）

## しくみ

- `assets/site.css` … 全ページ共通のスタイル
- `assets/site.js` … コピー、カウントダウン、次の夜祭、機種の切り替え、トップの体験
- `assets/trailer.mp4` … 予告編
